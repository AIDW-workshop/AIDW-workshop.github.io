# Agents in Digital Worlds (AIDW)

A simple, responsive website for the proposed CVPR 2027 workshop.

## Editing

Edit `index.html` for workshop content and `style.css` for presentation. Assets are in `assets/`. No build tools or external dependencies are required.

## Preview

Run `python3 -m http.server 8000` in this directory and open http://localhost:8000.

## Publishing

GitHub Pages serves the `main` branch from the repository root. Push changes to `main` to update the website.

## Content status

Content is based on the supplied workshop proposal. The workshop, dates, schedule, submission details, and participation statuses are provisional. Update these after official confirmation. The proposal itself is not included in this repository.
